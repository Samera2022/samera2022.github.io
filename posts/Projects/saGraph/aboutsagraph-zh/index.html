saGraph — 依赖感知的桌面任务小组件

它是什么#

saGraph 是一个跨平台桌面小组件（Windows 与 Linux），把待办列表和它的任务依赖图放在桌面上。它不是又一个清单工具；重点在于表达什么卡住了什么，然后一眼看清整个结构。

你的数据留在你自己的机器上。不需要账号、不需要登录，也不需要同步服务器。

它能做什么#

常驻桌面。 一直在那儿的面板，可置顶、可拖动，分类分组可折叠。点一下任务就能在完成与未完成之间切换。

正经处理依赖。 一个任务的前置条件是关于其他任务的布尔表达式，支持 AND / OR / NOT 和任意嵌套。空 And([]) 恒为真，空 Or([]) 为假，无前置条件视为满足，所以简单条件和复杂条件都能干净表达。

不怕成环。 求值带访问栈，遇到环时按“不满足”处理，而不是无限递归。你完全可以手写出一条环，saGraph 不会因此卡死。

把图画出来。 独立窗口渲染整张依赖图，支持拖拽和连线来编辑，而不是对着一份平铺列表去脑补依赖关系。

在独立窗口里编辑。 增删改任务、分类和依赖表达式都在专门的编辑器里完成，编辑时不会和常驻面板打架。

安静工作。 跟随系统深浅色、开机自启、单实例、常驻系统托盘。

它和其他工具差在哪#

主流任务管理工具大多把依赖当作事后补充，甚至根本不支持。Todoist 只有基础的阻塞关系。Asana 和 Monday 虽然有依赖，却把它们关在有账号、席位和订阅的网页应用里。而大多数桌面待办小组件，只是把一张清单钉在壁纸上，对先后顺序毫无概念。

saGraph 把依赖图当作主角。

列表优先的应用网页项目工具saGraph
依赖关系基础或没有有，但绑定网页一等公民，支持 AND / OR / NOT
图形视图罕见看板或时间线可交互的 DAG 窗口
桌面常驻有小组件，无依赖无面板与图形，始终在场
账号通常需要需要不需要
数据他们的云他们的云你的机器，本地 JSON
成环不处理不处理显式处理，安全降级

于是它回答的正是别的工具回答不了的两个问题：你现在能做什么，以及某件事为什么卡住了。

付费能力#

依赖图窗口是首个付费能力，在运行时门控，而不是把按钮藏起来：

授权类型PERSONAL / COMMERCIAL / ENTERPRISE
有效期1M / 3M / 6M / 1Y / LIFETIME
试用一次 7 天本地试用

签名后的激活码把授权绑定到机器码。客户端用 RSA PKCS#1 v1.5 和 SHA-256 验签，并以 AES-GCM 加密存储。状态是显式的：NOT_VERIFIED、VALID、EXPIRED、INVALID、TRIAL、TRIAL_EXPIRED。完整性探针失败时软降级：免费功能照常，付费能力拒绝。

技术栈#

  • 框架：Tauri 2.x（Rust 与 Web），单一代码库编译到 Windows 和 Linux
  • 前端：TypeScript、Svelte、Vite、Tailwind CSS
  • 依赖图：Cytoscape.js 配合 dagre 布局
  • 存储：本地 JSON，Repository trait 抽象，带时间戳备份轮转，便于日后替换成 SQLite 或云同步

sagraph-core 是纯 Rust，不依赖 Tauri、不依赖平台 API。依赖代数、解锁规则和 CRUD 都在其中，平台壳只做薄封装，所以未来做 CLI、移动端或 Web 都不必重写。
